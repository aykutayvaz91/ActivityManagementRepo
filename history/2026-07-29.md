Tasks yorum eki + Employee foto + Admin logo'da uygulandı. `Startup.cs` static dosyalarda `X-Content-Type-Options: nosniff` + `/uploads` altında görsel-olmayanlar `Content-Disposition: attachment` → yüklenen içerik tarayıcıda çalışmaz.
- **K2 Talep detayı IDOR:** `ServiceRequestAppService.GetAsync`/`GetEffortsAsync` artık `ApplyVisibilityScope` uyguluyor (listelerle aynı kapsam). Önceden Uzman URL'den herhangi talebin detay/yorum/dosya/eforunu görebiliyordu.
- **K3 Rapor IDOR:** `IReportAppService.GetPersonal/TeamReportAsync` → `[RemoteService(false)]`; kapsam yalnız `ReportsController`'da. Uzman artık `/api/services/app/report/...` ile başkasının raporunu çekemez.
- **K4 Yorum/açıklama stored XSS:** `SafeHtml` regex yerine **Ganss HtmlSanitizer 9.1.973** (beyaz-liste). `<img/src=x/onerror=...>` bypass'ı temizlenir; ekran görüntüsü için yalnız `data:image/*` korunur. (Yeni bağımlılık: HtmlSanitizer + AngleSharp + AngleSharp.Css.)
- **K5 Portal ek indirme SSRF/token sızması:** `DownloadPortalAttachmentAsync` `att.Url`'i https + host allow-list (BaseUrl host + `cortixsuite.azurewebsites.net`) + özel/loopback IP reddiyle doğruluyor; token yalnız doğrulanan host'a.
- **K6 CSRF:** `TasksController` Create/Edit/Delete/UpdateStatus/AddComment/Approve/Reject → `[ValidateAntiForgeryToken]` (Startup'ta global antiforgery filtresi YOK; doğrulandı). Form'lar oto-token, Kanban AJAX token gönderiyor.

**Deploy:** `dotnet publish` ile tam bağımlılık kapanışı → site'a deps.json + HtmlSanitizer/AngleSharp DLL'leri senkronlandı. **Smoke:** admin giriş + yorumlu talep (3277) Detay HTTP 200, "Portal Yorumları" render → HtmlSanitizer runtime'da yükleniyor. AppVersion 1.16.5 → **1.17.1**.
