# FAZ 2 — Entegrasyon altyapısı (kendi tarafımız) — AYNI GÜN tamamlandı

Kullanıcı: "kendi tarafımızı yazalım hazır olsun" + "konfig ayarlarını admin yapabilmeli, arayüzü yap". Ayrıca iki portal ekran görüntüsünden alan analizi yapılıp **iki hand-off dokümanı** üretildi: `destek-entegrasyon.md`, `psm-entegrasyon.md`.

## Yapılanlar
- **Ayar entity'leri (DB, admin yönetir):** `IntegrationSettings` (singleton: InboundApiKey, SyncEnabled, IntervalMinutes) + `IntegrationSource` (kaynak başına: Enabled, BaseUrl, ApiKey, AuthHeader/AuthScheme, Filter, InitialLookbackDays, LastSyncUtc/LastRunUtc/LastResult). **Migration `V6_Integration`** (canlıda uygulandı). Seed: Sunucu+Destek 2 satır (kapalı) + settings satırı (idempotent).
- **`IIntegrationSettingsAppService`**: GetAsync/SaveGeneralAsync/SaveSourceAsync (admin), `GetInboundAsync` (anonim webhook için), anahtarlar EmailSettings deseninde (boş=değişmez; ayrıca "temizle" seçeneği → webhook kapatılır).
- **Admin ekranı** `/Admin/Integration` (+ Admin panel kartı): Gelen(webhook) anahtarı + webhook adresi gösterimi + master pull switch + aralık; her kaynak için (Sunucu/Destek) Enabled/BaseUrl/ApiKey/Auth/Filter/lookback + **son çalışma/watermark/sonuç** göstergesi.
- **Webhook alıcısı** (`IntegrationController`) artık inbound anahtarı **DB'den** okur (appsettings değil); yoksa 503.
- **`UpsertFromPortalAsync` zenginleştirildi:** ham alan çözümleme — `assigneeEmail`→Employee, `group`→Team, `statusText`→RequestStatus (TR/EN varyant eşleme), `priorityText`→PriorityScore. Atama/durum yerelde korunur; portal yalnız kapanış/iptal bildirince kapatır. İlk içe aktarımda portal ataması uygulanır.
- **`RequestSyncHostedService`** (PULL): DB'den aktif kaynakları okur, portal okuma ucundan JSON çeker (`{items:[...]}` zarfı veya düz dizi), `WireItem`→`PortalRequestDto` map (psm `requested/installed/services` → ExtraInfo düz metin, **parola yok**), `UpsertFromPortalAsync` ile idempotent, watermark ilerletir. **Varsayılan KAPALI** (SyncEnabled=false → no-op). Startup'ta `AddHttpClient` + `AddHostedService`.

## Parti 1 — Güvenlik/tutarlılık (commit 0cad597)

## Parti 4 — API yetki denetimi (commit 0cad597)
Denetim ajanı dynamic API açıklarını buldu; kapatıldı:
- **YÜKSEK:** `Employee.UpdateRole` (→EnsureAdmin), `WorkflowStatus.Create/Update/Delete` (→EnsureAdmin), `ServiceRequest.UpsertFromPortal` (kimliği doğrulanmış non-admin'e guard).

- Not: `[RemoteService(false)]` bu ABP sürümünde uçları gizlemedi (415/200 döndü) → çalışma-zamanı guard kullanıldı (anonim webhook + HostedService + Admin geçer, diğer authenticated reddedilir). Doğrulandı: anonim webhook 200, InboundApiKey DB'de şifreli (314 krkt).
