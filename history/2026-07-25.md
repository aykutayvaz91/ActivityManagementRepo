### Veri modeli
- **Yeni entity `ServiceRequest`** (`Core/Entities/ServiceRequest.cs`): Source, ExternalRef/ExternalUrl (portal no+link), Title/Description, Requester(Name/Email), ExtraInfo (sunucu/müşteri), Status (`RequestStatus`: Yeni/Atandı/DevamEdiyor/Beklemede/Çözüldü/Kapandı/İptal), Priority + PriorityScore(1-10), Assigned/Secondary/Team, Category/SubCategory/Project, ReceivedDate/DueDate/ResolvedDate/ClosedDate, CompletionPercentage, Logs.
- **`ActivityLog.ServiceRequestId`** (+nav) → efor birleşik tabloya yazılır, Günlük Efor otomatik kapsar.
- DbContext: DbSet + konfig (indeks `(Source,ExternalRef)`, FK'ler SetNull/Restrict/NoAction).
- **Migration `V5_ServiceRequests`** (20260725054912) — ServiceRequests tablosu + ActivityLogs.ServiceRequestId. Canlıya açılışta uygulandı (doğrulandı: tablo+kolon var, __EFMigrationsHistory'de kayıtlı).

### Application
- `ServiceRequests/Dto/ServiceRequestDto.cs` (+ CreateUpdate, GetInput, **PortalRequestDto** Faz 2 için).
- `IServiceRequestAppService` + `ServiceRequestAppService`: GetAll (Source/Status/Assignee/MineOnly/OnlyOpen filtre + **takım izolasyonu + admin-self** deseni), Get, Create/Update/Delete (yönetici), **Assign** (yönetici), **UpdateStatus** (atanan/yönetici; duruma göre ilerleme %), **LogEffort** (yalnız atanan kişi — faaliyet kuralı), GetEfforts, DeleteEffort, **UpsertFromPortalAsync** (idempotent `(Source,ExternalRef)`).

### Web (arayüz)
- **`RequestsController`** + görünümler: `Requests/Index` (2 sekme: Sunucu/Destek + Ata/Durum/Efor modalleri + Yeni Talep), `_RequestTable` (partial), `Requests/Detail` (bilgi + efor listesi + ekle/durum/ata formları).
- **`WorkController` + `Work/Index`** — "İşlerim → Genel Bakış": açık **Görev + Talep + Faaliyet** tek listede, gecikmiş→yakın SLA→yüksek önem sırasıyla, özet kartlar. Personelsiz hesapta (Sistem Yöneticisi) bilgilendirme.

- **Günlük Efor**: efor formuna "Talep" hedefi (bana atanan açık talepler); listede "Talep: ..." gösterimi.
- **Menü yeniden düzenlendi** (`_Layout`): **İşlerim** dropdown (Genel Bakış · Görevlerim/Görevler · Pano · Faaliyetler · Görev Sorgula) + **Talepler** dropdown (Tüm/Sunucu/Destek) + Günlük Efor · Projeler · Personeller · Raporlar · Admin. Pano artık İşlerim altında. `#tab-destek/#tab-sunucu` ile sekme otomatik açılır.
